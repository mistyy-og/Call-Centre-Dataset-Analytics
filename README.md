# 📊 Call Centre Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing call centre operations and customer service performance using **Microsoft Power BI** and **Microsoft Excel**.

The dashboard transforms raw call centre data into interactive visual insights that help managers and business teams understand agent performance, call activity, operational trends, and customer satisfaction.

The project is designed to support data-driven decision-making and identify opportunities to improve call centre efficiency and customer experience.

## 🎯 Business Objective

The main objective of this project is to analyze call centre data and answer important business questions such as:

* How many calls are being handled?
* How quickly are calls being answered?
* Which agents handle the highest number of calls?
* What is the average call handling time?
* What is the call resolution rate?
* How satisfied are customers?
* When are call volumes highest?
* Which days or times experience peak call activity?
* Which agents or teams are performing best?
* Where are opportunities to improve customer service?

---

## 📊 Key Analysis Areas

### 👨‍💼 Agent Performance

The dashboard evaluates individual and overall agent performance using metrics such as:

* Calls handled
* Average call handling time
* Call resolution rate
* Answer speed
* Customer satisfaction

This helps identify high-performing agents and areas where additional support or training may be required.

---

### 📞 Call Activity & Trends

Call activity is analyzed across different time periods to identify operational patterns.

The analysis includes:

* Call volume
* Calls by day
* Calls by time period
* Peak call periods
* Call trends over time

Understanding peak periods can help managers improve staffing and resource allocation.

---

### 😊 Customer Experience

Customer satisfaction is analyzed alongside call activity and agent performance.

The dashboard helps identify:

* Customer satisfaction patterns
* Service quality trends
* Resolution performance
* Potential areas for customer experience improvement

---

## 📈 Dashboard KPIs

The dashboard focuses on important call centre KPIs including:

| KPI                   | Purpose                                               |
| --------------------- | ----------------------------------------------------- |
| Total Calls           | Measures overall call volume                          |
| Calls Answered        | Measures successfully answered calls                  |
| Answer Speed          | Measures how quickly calls are answered               |
| Average Handle Time   | Measures average time spent handling calls            |
| Resolution Rate       | Measures how effectively customer issues are resolved |
| Customer Satisfaction | Measures customer experience                          |
| Agent Performance     | Compares individual agent performance                 |
